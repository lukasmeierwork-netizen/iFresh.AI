# eyefreshAI

iOS-only Expo app for the EyefreshAI assistant — tracks viewing distance, blink rate,
and continuous screen time; runs guided eye tests; and offers an on-device AI
companion for eye-care reminders.

## Requirements

- Node 20+
- Xcode 15+ (iOS 15.5 deployment target)
- Yarn 1.22 (the pinned `packageManager`)
- CocoaPods (installed automatically by `expo prebuild` / `expo run:ios`)

## Get started

1. Install dependencies

   ```bash
   yarn install
   ```

2. Start the Metro dev server

   ```bash
   yarn start
   ```

3. Build and run on iOS (device or simulator)

   ```bash
   yarn ios
   ```

The `ios/` folder is generated by Expo prebuild and is gitignored — re-run
`yarn ios` (or `npx expo prebuild --clean`) after pulling.

## Environment

Copy `.env.example` to `.env.local` and fill in your Supabase credentials:

```bash
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
```

See `docs/supabase-auth-setup.md` for the OAuth redirect configuration.

## Project layout

- `src/app` — file-based routes (expo-router). `(tabs)` holds the main bottom-tab section.
- `src/components` — UI components grouped by feature (chat, onboarding, schedule, …).
- `src/hooks` — shared React hooks.
- `src/lib` — platform-agnostic utilities, Supabase client, chat repository, vision helpers.
- `src/constants/theme.ts` — design tokens (colors, spacing, shadows).
